JS Directory
============
Shared JavaScript libraries and app glue used by client and staff interfaces.

Key Files
---------
- jquery-3.7.0.min.js and jquery-ui-1.13.2.custom.min.js – core UI toolkit.
- jquery-ui-timepicker-addon.js, jquery-ui-sliderAccess.js – time/slider widgets.
- select2.min.js, bootstrap-typeahead.js – selection and suggestion widgets.
- redactor-*.js – WYSIWYG editor and osTicket plugins.
- filedrop.field.js – drag-and-drop attachments.
- jquery.pjax.js – partial page loads.
- jstz.min.js – timezone detection.
- fabric.min.js – canvas helpers.
- osticket.js – application glue/behaviors for the client UI.

Notes
-----
- Staff-only scripts live in scp/js/; installer scripts are in setup/js/.
