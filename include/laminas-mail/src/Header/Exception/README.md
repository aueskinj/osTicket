Header Exceptions
=================
Header-specific exceptions used by laminas-mail header implementations.

Contents
--------
- BadMethodCallException.php – improper method use in header contexts.
- ExceptionInterface.php – marker for header exceptions.
- InvalidArgumentException.php – invalid header values or parameters.
- RuntimeException.php – runtime failures during header parsing/formatting.

Notes
-----
- Vendor code; rely on upstream fixes. See https://docs.laminas.dev/laminas-mail/ for guidance.
