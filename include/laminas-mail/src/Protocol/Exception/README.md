Protocol Exceptions
===================
Exceptions used by laminas-mail protocol clients.

Contents
--------
- ExceptionInterface.php – marker interface for protocol exceptions.
- InvalidArgumentException.php – invalid parameters or state during protocol operations.
- RuntimeException.php – runtime failures in IMAP/POP3/SMTP exchanges.
