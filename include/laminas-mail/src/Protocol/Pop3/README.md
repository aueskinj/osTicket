POP3 Helpers
===========
POP3-specific helpers for laminas-mail protocol handling.

Contents
--------
- Response.php – parses POP3 server responses.
- Xoauth2/ – POP3 XOAUTH2 provider helpers (e.g., Microsoft.php).

Notes
-----
- Vendor code; avoid local modifications. Upstream docs: https://docs.laminas.dev/laminas-mail/.
- Changes can affect POP3 authentication and parsing behavior; prefer upstream updates.
