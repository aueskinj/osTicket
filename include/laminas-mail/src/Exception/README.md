Exceptions
==========
Common exception types used throughout laminas-mail.

Contents
--------
- BadMethodCallException.php – invalid method invocation contexts.
- DomainException.php – domain/logic violations.
- ExceptionInterface.php – marker interface for component exceptions.
- InvalidArgumentException.php – invalid argument validation failures.
- OutOfBoundsException.php – access outside valid bounds/collections.
- RuntimeException.php – runtime errors from protocol, storage, or transport operations.

Notes
-----
- Vendor code; prefer upstream fixes over local changes. See https://docs.laminas.dev/laminas-mail/ for details.
