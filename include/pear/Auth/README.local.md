PEAR Auth (Local Note)
======================
Authentication helpers bundled from PEAR.

Contents
--------
- SASL.php – loader/wrapper for SASL mechanisms.
- SASL/ – SASL mechanism implementations (Anonymous, Plain, Login, CramMD5, DigestMD5, External, SCRAM, Common base).

Notes
-----
- Vendor code; avoid modifying. Used by mail/auth flows in osTicket.
