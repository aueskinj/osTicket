Assets Directory
================
Shared static assets referenced by css/ and js/ bundles.

Contents
--------
- default/ – base theme imagery, LESS/CSS sources, and documentation (Theme-How-To.rst) for skinning.
- font/ – packaged webfonts (Font Awesome) used by UI icons.

Notes
-----
- Override imagery and theme assets here when building a custom skin; CSS references expect paths relative to this folder.
