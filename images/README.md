Images Directory
================
Shared artwork for client and staff interfaces.

Contents
--------
- favicon.png plus oscar-favicon-16x16.png / -32x32.png – favicons.
- FhHRx-Spinner.gif – loading indicator.
- avatar-sprite-ateam.png, mystery-oscar.png – avatar placeholders/sprites.
- cal.png – calendar icon.
- flags.png – sprite sheet used by flags.css.
- captcha/ – captcha backgrounds and glyphs used by captcha.php.

Notes
-----
