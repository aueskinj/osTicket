Staff CSS
========
Stylesheets for the staff control panel.

Contents
--------
- Core styles: scp.css, dashboard.css, dropdown.css, login.css, tooltip.css, translatable.css.
- Widgets: spectrum.css (color picker).

Notes
-----
- Keep CSS aligned with markup in include/staff templates.
- Avoid embedding business logic; use CSS variables/classes driven by controllers/templates.
