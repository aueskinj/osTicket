Staff JS
=======
JavaScript assets for the staff control panel.

Contents
--------
- Framework helpers: scp.js, thread.js, ticket.js, tips.js.
- UI components: jb.overflow.menu.js, jquery.dropdown.js, jquery.translatable.js, spectrum.js, bootstrap-tab.js, bootstrap-tooltip.js.
- Charts/utilities: g.raphael.js, g.dot-min.js, g.line-min.js, raphael-min.js.
- Modules: dashboard.inc.js, upgrader.js.

Notes
-----
- Keep logic in JS modular and align with server-side permissions and data payloads.
- Validate changes against supported browsers for the control panel.
