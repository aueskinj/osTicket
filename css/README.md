CSS Directory
=============
Core stylesheets for client and shared UI components.

Key Files
---------
- osticket.css – primary UI styling for the client portal.
- redactor.css / redactor plugins – WYSIWYG editor skin.
- select2.min.css, typeahead.css, jquery-ui-timepicker-addon.css – vendor widget skins.
- flags.css – flag sprite sheet definitions.
- thread.css – ticket/thread view styling.
- rtl.css – right-to-left overrides.
- loadingbar.css – progress indicator styling.
- ui-lightness/ – jQuery UI theme assets.

Notes
-----
- Staff-specific CSS lives under scp/css/; installer styling is in setup/css/.
